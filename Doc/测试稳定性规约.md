# 单元测试稳定性规约

> 目标：VS2026 全量跑测与 `dotnet test`（含 `run-tests.ps1` 全宿主）**首跑即绿**，且不显著变慢。
> 本规约约束 NewLife.Core 仓库全部测试工程（XUnitTest.Core / XUnitTest.Net6 / XUnitTest.Compat / XUnitTest.SourceGenerator）。

## 1. 硬规则（新增/修改测试必须遵守）

| # | 规则 | 反例 | 正例 |
|---|------|------|------|
| 1 | **不依赖外网与外部服务**：公网 HTTP、真实 DNS 一律本地化（本地服务桩/注入桩/自签证书） | 直接请求 `star.newlifex.com`，网络抖动即红 | 本地 `HttpServer` 桩 + `DnsResolver.Set` 把域名指向本机 |
| 2 | **等待一律条件轮询**，禁止用固定 Sleep 作为唯一等待手段；超时仅作防挂起兜底（≥5 秒），不作为性能判定 | `Thread.Sleep(1000)` 后断言计数 | `TestWait.Until(() => count >= 1, 10_000)` |
| 3 | **断言右值不得使用断言时刻的 `DateTime.Now`**；涉及时间推移的断言必须捕获动作前时间戳 | `Assert.True(endpoint.NextTime >= DateTime.Now.AddSeconds(1))` | `var t0 = DateTime.Now; ...` 断言 `NextTime >= t0.AddSeconds(1)` |
| 4 | **进程级全局态改写必须恢复或串行化**（`Tracer/XTrace/BasePath/Setting/ActivityListener/DnsResolver.Instance` 等）；不能恢复的用例并入 `GlobalState`/`Telemetry` 串行集合 | 并行用例挂/卸全局 ActivityListener | `[Collection("Telemetry")]` + `DisableParallelization=true` 集合 |
| 5 | **网络用例端口策略**：单协议用动态端口（`Port=0`）；双协议组合用 `TestPort` 分配，不得硬编码端口 | `new NetServer { Port = 8080 }` | `Port = 0`，或 `TestPort.StartAny(...)` 顺延重试 |
| 6 | **性能/吞吐阈值只允许语义化口径**，严格阈值断言迁至 `Benchmark/` 工程 | 断言"100ms 内必须完成" | 断言"取消后不等到读超时才结束（10 秒兜底）" |
| 7 | **环境工具缺失显式跳过并留痕**，不得失败 | 无 7z.exe 时直接开工导致异常 | 探测 `SevenZip` 可用性，缺失时写入日志并 return |

## 2. 工具箱

| 工具 | 位置 | 用途 |
|------|------|------|
| `TestWait.Until/UntilAsync/CompletedAsync` | `XUnitTest.Core/Common/TestWait.cs` | 条件轮询等待、任务限时完成 |
| `TestPort.StartAny` | `XUnitTest.Core/Net/TestPort.cs` | 双协议用例的动态端口分配（候选段顺延重试） |
| `DnsResolver.Instance.Set(host, addrs)` | 产品 `NewLife.Core/Net/IDnsResolver.cs` | 把域名指向本机，构造脱网用例 |
| `DnsResolver.ResolveHostAsync`（`protected virtual`） | 同上 | 子类注入确定性解析桩（测试专用最小缝） |
| 本地服务桩 | `HttpServer`/`HttpListener` + 仓库自签 pfx（`certs/newlifex.com.pfx`） | 替代公网站点，覆盖 HTTP/TLS 语义 |
| `TestBlackhole` | `XUnitTest.Core/Common/TestBlackhole.cs` | 本机连接黑洞（loopback 打满 backlog + 自检），构造建连超时用例，替代文档网段 |

## 3. 验收流程

| 场景 | 命令/方式 | 通过标准 |
|------|----------|---------|
| 本地轮次压测 | `pwsh run-tests.ps1 -Repeat 10`（`-SkipBuild` 可复用产物） | 全部轮次零失败 |
| VS2026 全量 | Test Explorer 全量跑测（根 `.runsettings` 已把宿主并行限为 5） | 首跑零失败 |
| CI | `test.yml`（`test.ci.runsettings` 把 4 核 runner 的并行线程限为 4；附 `--blame-hang` 挂起转储） | test 矩阵 10 个 job 全绿 |
| 断网验证 | 阻断外网后跑全量 | 零失败（证明用例完全本地） |

## 4. 已知踩坑（保留案例，防止回归）

- **竞速调用用例**：断言用断言时刻 `DateTime.Now` 作右值，满载调度停顿 >2s 即误报（已改为捕获动作前 `t0`）。
- **OTel 监听器串扰**：采集器用例挂载"监听全部源"的进程级监听器，与跟踪器"无监听者"用例并行即互相污染（已并入 `Telemetry` 串行集合）。
- **DnsResolver 真实解析**：同步刷新走真实 `Dns.GetHostAddressesAsync` 且 5s 超时，满载超时即保留旧值误报（已加 `ResolveHostAsync` 缝 + 确定性桩）。
- **公网冒烟**：`GetStringWithDnsResolver2` 曾因站点 502 在 CI 整批变红（本地化进行中）。
- **7z.exe 环境依赖**：CI runner 缺失工具导致 `SevenZipTests` 四例失败（改为工具探测跳过）。
- **类初始化互等死锁**：finalizer 线程经 `Pool.OnGen2 → Runtime.TickCount64` 触碰静态初始化，与 `TimerScheduler` 监视器互等导致整轮挂起（产品已修两处；CI 加 `--blame-hang` 监控）。
- **UDP 用例**：UDP 不可靠，满载下回环也会丢包（多数据报拉取曾 15 秒超时）；等待必须"有界重发 + 事件断言"，不得单发单等，超时须取消挂起的接收。
- **连接超时用例**：曾连文档网段 `192.0.2.1` 制造黑洞，网络环境不同即结果不定（已改 `TestBlackhole` 本机黑洞与本地拒绝端口）。
- **竞速负载均衡**：默认探测会真实访问服务地址并异步改写端点状态（Rtt/Errors），与排序断言存在竞态窗口（已注入确定性探测桩）。
